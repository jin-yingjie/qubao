# 🐾 趣宝（Qubao）

一只会呼吸、会摇尾巴的桌面小宠物，还能帮你写便签和专注工作。

基于 **Electron** 开发，支持 Windows / macOS / Linux。

---

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 🐱 桌宠 | 一只可爱的小猫悬浮在桌面，有呼吸动画和尾巴摆动 |
| 📝 便签 | 点击桌宠 → 新建便签，可以拖动位置，自动保存内容 |
| ⏰ 番茄钟 | 25/5/15 分钟三种模式，帮助专注工作 |
| ⚙️ 设置 | 切换角色、工作模式（降低存在感） |
| 📌 系统托盘 | 右键托盘图标可以快速打开功能 |
| 💾 位置记忆 | 桌宠拖动后的位置会自动记住 |

## 🚀 快速开始（3 步跑起来）

### 前置条件
- **Node.js** ≥ 16.0（[官网下载](https://nodejs.org/)）
- 推荐 **npm** ≥ 8.0

### 第 1 步：安装依赖

```bash
cd qubao    # 进入项目根目录
npm install
```

> 第一次安装会下载 Electron（大约 100MB），请耐心等待。
> 如果下载慢，可以设置淘宝镜像：
> ```bash
> npm config set registry https://registry.npmmirror.com
> npm install
> ```

### 第 2 步：运行

```bash
npm start
```

几秒后你会看到：
- 桌面右下角出现一只 🐱 小猫
- 系统托盘（右下角小箭头那里）多了一个图标

点击小猫会弹出功能菜单，拖动它可以换位置。

### 第 3 步：打包成独立程序（可选）

如果你想把它变成一个 `.exe` 文件发给朋友：

```bash
# Windows（会在 dist/ 目录生成安装包）
npm run build:win

# macOS
npm run build:mac
```

打包工具使用的是 `electron-builder`，第一次运行会自动下载所需的依赖。

| 操作 | 效果 |
|------|------|
| **单击小猫** | 弹出功能菜单（便签/番茄钟/设置） |

## 📂 项目结构

```
qubao/
├── package.json          # 项目配置（依赖、脚本）
├── main.js               # 主进程（窗口管理、托盘、IPC）
├── preload.js            # 安全桥接层（暴露给渲染进程的 API）
├── assets/
│   └── icon.png          # 程序图标（请自己放一张）
└── src/
    ├── pet/              # 桌宠窗口（小猫本体）
    │   ├── index.html    #   页面结构
    │   ├── style.css     #   动画样式
    │   └── script.js     #   交互逻辑
    ├── menu/             # 点击桌宠弹出的菜单
    ├── settings/         # 设置面板
    ├── note/             # 便签窗口
    └── pomodoro/         # 番茄钟窗口
```

### ⚙️ 架构简述（给开发者）

```
  主进程 (main.js)
       │
       ├── 创建 BrowserWindow（透明窗口 + 无边框 + 置顶）
       ├── 创建 Tray（系统托盘）
       └── 管理多个子窗口（菜单/便签/番茄钟/设置）

  IPC 通信 (preload.js 暴露 petAPI)
       │
       ↓
  渲染进程（纯 HTML + CSS + JS，每个窗口一个独立的页面）
```

这种"每个功能是一个独立 BrowserWindow"的设计，让每个小功能都像桌面里的"小工具"一样，非常灵活。

## ❓ 常见问题

**Q: 运行后没看到小猫？**
- 检查系统托盘是否有图标（可能被折叠在"上箭头"里）
- 看控制台有没有报错信息（`npm start` 后会有终端输出）

**Q: 怎么关闭程序？**
- 右键系统托盘图标 → 退出
- 或者在终端里按 Ctrl+C 停止 `npm start`

**Q: 想换成一只小狗/别的图片？**
- 编辑 `src/pet/index.html`，把 SVG 换成 `<img src="your-image.gif">` 即可
- GIF / APNG 动画图片最适合（可以做循环动画）

**Q: 小猫挡住了我的工作窗口怎么办？**
- 打开设置 → 勾选「工作模式」，它会变小且半透明
- 或者直接拖到角落里
